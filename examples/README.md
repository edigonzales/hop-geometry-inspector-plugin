# Data Inspector examples

Requires Hop 2.19, Geometry Type and Data Inspector. Each pipeline embeds its small dataset and uses standard Hop transforms.

- [rows](rows/README.md)
- [geometry](geometry/README.md)
- [layers](layers/README.md)
- [streams](streams/README.md)
- [Configured error output](errors/README.md): two valid rows and one rejected conversion.

Use **Inspect data...** in the transform context menu. Try **Sample** and **All rows (temporary)** on the same stream to compare the capture modes.
